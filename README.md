Mô tả dự án

Online Quiz System là một hệ thống trắc nghiệm trực tuyến giúp người dùng có thể tham gia làm bài kiểm tra và quản lý các bài kiểm tra một cách dễ dàng. Hệ thống hỗ trợ người dùng đăng ký, đăng nhập, làm bài trắc nghiệm, xem kết quả và quản trị viên có thể quản lý câu hỏi, bài kiểm tra.

Công nghệ sử dụng

Ngôn ngữ lập trình: PHP

Cơ sở dữ liệu: MySQL

Máy chủ cục bộ: XAMPP

Front-end: HTML, CSS, JavaScript

Tính năng chính

1. Người dùng (Sinh viên)

Đăng ký, đăng nhập

Chọn bài kiểm tra

Làm bài trắc nghiệm

Feedbacks cho người dùng

Xem kết quả bài kiểm tra

2. Quản trị viên

Quản lý câu hỏi (Thêm, sửa, xóa)

Quản lý bài kiểm tra (Tạo, chỉnh sửa, xóa)

Quản lý người dùng

Xem báo cáo kết quả

Xem feedbacks của người dùng

Hướng dẫn cài đặt

1. Cài đặt XAMPP

Tải và cài đặt XAMPP

Mở XAMPP và chạy Apache và MySQL

2. Cấu hình cơ sở dữ liệu

Mở trình duyệt, truy cập http://localhost/phpmyadmin/

Tạo database mới với tên bokas_db

Import file bokas_db.sql (có trong thư mục database của dự án)

3. Chạy dự án

Copy thư mục dự án vào htdocs của XAMPP

Mở trình duyệt và truy cập http://localhost/Bokas (trang này cho người dùng)

Mở trình duyệt và truy cập http://localhost/Bokas/adminpanel (trang này cho admin)
